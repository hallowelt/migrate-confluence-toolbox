# Migrate Confluence: Toolbox

This is a companion repository to the main
[Migrate Confluence tool](https://github.com/hallowelt/migrate-confluence/),
containing some helper scripts and one-off tools for special occasions.

> **Attention!** The tools in this repo are provided in the hope that they
> might be useful, but **without any warranty**!
>
> They are written and reviewed with the same care as all software released by
> Hallo Welt. However, some tools are vibe-coded, some were not tested by us
> against specific Confluence versions, and some might’ve become outdated as
> the main tool evolves.
>
> Use with care and at your own risk!

Each tool is placed in its own subfolder with its own README. Please read that
file before using the tool. Thank you!
